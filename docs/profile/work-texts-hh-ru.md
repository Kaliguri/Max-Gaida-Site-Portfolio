## Alebardium

**Unity Developer / Frontend Developer / UI/UX Designer**
Май 2026 — Август 2026 (4 месяца)

Личная мини-студия. Вдвоём с дизайнером делаем UI-ассеты для Unity и коммерческие сайты на фрилансе: я отвечаю за разработку, архитектуру и UX, дизайнер — за визуал.

ЗАДАЧИ
- Разработка и выпуск UI-ассета Bloodlines UI для Unity: префабы, состояния контролов, 9-slice спрайты, две цветовые темы, демо-сцена, упаковка и публикация.
- Разработка Bloodlines UI 2.0 Toolkit — инструмента темизации интерфейса: Theme Editor на UI Toolkit, валидатор тем (Theme Doctor), мастер подключения к проекту, переключение тем в рантайме на uGUI, русская и английская локализация редактора.
- Frontend коммерческого сайта «Послесловие» для бренда косметики: лендинг, оформление заявки с созданием сделки в AmoCRM, правка контента без кода, SEO, аналитика.
- Проектирование компонентов и сценариев вместе с дизайнером, перенос дизайна в код, плагин для Figma (Tint Exporter) для передачи ассетов в Unity.
- Поддержка выпущенных продуктов и работа с отзывами пользователей.

СТЕК
Unity, C#, uGUI, TextMeshPro, UI Toolkit, ScriptableObject, NUnit, Unity MCP, Next.js, React, TypeScript, Tailwind, Zod, Playwright, GitHub Actions, Cloudflare Workers, AmoCRM, Figma, Git.

РЕЗУЛЬТАТЫ

Для Asset Store это сильные цифры: за 3,5 месяца ассет скачали 1 750 раз — это более 1 500 реальных пользователей, разработчиков, которые планировали использовать его в своих проектах. Ещё 2 557 получений, около 9,6 тыс. просмотров страницы, 129 добавлений в избранное, конверсия страницы 26,6%.
- Запустил в прод сайт «Послесловие» (posleslovie.online) с интеграцией в CRM. Контент клиент правит сам, публикация занимает около 3 минут, платный хостинг не нужен.
- Собрал основу Bloodlines UI 2.0 Toolkit (196 коммитов проекта). Завершение зависит от финальных ассетов дизайнера.
- Выпустил плагин Tint Exporter для экспорта tint-масок из Figma в Unity.
